# Ґніт: Попелясті Глибини

Маленька 2D-метроїдванія в браузері (HTML5 Canvas, один файл `index.html`, без залежностей).

Ти — Ґніт, жива свічка, що спускається в темні печери, щоб знову розпалити згасле горно.

## Як грати
Відкрий `index.html` у браузері (або виклади на будь-який хостинг, напр. GitHub Pages).

| Дія | Клавіші |
|---|---|
| Рух | ← → / A D |
| Стрибок (тримай — вище) | Z / Пробіл |
| Удар (↑/↓ + удар — вгору/вниз, удар вниз у повітрі відштовхує) | X |
| Ривок | C / Shift |
| Лікування (тримати, витрачає сяйво) | F |
| Відпочити / зберегтися біля святилища | ↑ |
| Мапа / Пауза | M / Esc |

Працює також геймпад і сенсорні кнопки на телефоні.

## Світ
8 кімнат, 3 здібності (ривок, стрибки від стін, подвійний стрибок), приховані скарби, тріснуті стіни, бос — Попелястий Вартовий.
Кімнати описані ASCII-картами в `ROOM_DATA` всередині `index.html` — легенда символів у коментарі над ними.
