# Шахта-7

2D-метроїдванія в браузері (HTML5 Canvas, один файл `index.html`, без залежностей).
Робот-шахтар Б-7 спускається в покинуту шахту, щоб вимкнути збожеволіле ядро.

## Керування
| Дія | Клавіші |
|---|---|
| Рух / прицілювання | A D (W — вгору, S — вниз у повітрі) |
| Стрибок | Пробіл (тримай — вище); S + Пробіл — зіскочити з платформи |
| Постріл | J або ліва кнопка миші (тримай — заряджений постріл) |
| Ривок-бур | K / Shift або права кнопка миші |
| Станція (збереження, ремонт, магазин) | E |
| Мапа / пауза | M / Esc |

Також працюють стрілки + Z/X/C, геймпад і сенсорні кнопки.

## Вміст
- 5 регіонів, 19 кімнат, мапа з туманом війни і мінімапа.
- Здібності: бур (ривок, ламає тріснуті блоки), магнітні черевики (стрибки від стін),
  заряджений постріл (пробиває синю броню), реактивний ранець (подвійний стрибок).
- 6 видів ворогів (повзун, стрибун, літун, турель, щитоносець, падальник) і 2 боси.
- 7 секретів: фальшиві стіни й підлога, тріснуті блоки, броньовані люки, високі виступи.
- Станції з магазином апгрейдів за брухт.

## Розробка
Світ описано в `tools/world.py` (легенда тайлів — у шапці файлу). Після змін:
```
python3 tools/verify.py   # перевірка: порядок здібностей, секрети, немає пасток
python3 tools/build.py    # збирає index.html з tools/game.src.html + світу
```

# Козаки-розбійники (3D) — `kozaky/index.html`

Народна дворова гра в 3D-дендропарку (three.js). Ти — розбійник: шукай палки, викладай із них
стрілки на землі (3 палки = 1 стрілка, не рідше ніж кожні 40 м), а потім ховайся — козаки йдуть
по твоїх стрілках. Протримайся 3 хвилини або непомітно повернись до штабу.

Керування: WASD — рух, миша — огляд, Shift — біг, C — присісти, F — стрілка, Enter — «готово».
